# Changelog

## Experimental standalone cleanup

Package identity is `@vynxc/video-tauri`, with personal-account repository
metadata. Product-specific branding, design coupling and qualification settings
have been removed from the experimental tree. Runtime checks use the generic
`TAURI_VIDEO_` prefix. Native IPC remains protocol `1`; crate/package version and
public commands remain `0.4.0`.

Prior release notes, imports and source history remain available in Git history.
The original MIT and Apache-2.0 licenses are retained.
